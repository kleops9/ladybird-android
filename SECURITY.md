# Security Policy

This is the security policy of Ladybird for Android, an unofficial Android port of the Ladybird browser. The Ladybird
project's own policy is in [its repository](https://github.com/LadybirdBrowser/ladybird/blob/master/SECURITY.md).

## Reporting a vulnerability

Please report security issues privately, through GitHub's private vulnerability reporting: on this repository's Security
tab, choose "Report a vulnerability". Please don't report them as public issues.

If the issue is in the Ladybird engine and affects Ladybird on other platforms too, please also report it to the Ladybird
project, as its security policy describes, so that it's fixed for everyone.

A useful report names the app version (Menu › Settings › About Ladybird), your phone and Android version, and includes
a minimal test case that reproduces the issue.

## Supported versions

Only the latest release gets security fixes. Ladybird for Android is alpha software, and isn't ready to be relied on
for anything sensitive.
